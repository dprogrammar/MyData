**Product Analytics Tracking Demo — Amplitude + Live Landing Page**

I built a simple analytics demo to show how user activity can be tracked from a live landing page into Amplitude. The project captures user events from the deployed page and sends them to Amplitude Live Events, allowing real-time monitoring of visitor actions, location signals, and product interaction data.
